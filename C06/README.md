# C06

Arguments de `main` (`argc` / `argv`).

## Exercices

| Ex. | Fichier | Rôle |
|---|---|---|
| 00 | `ft_print_program_name.c` | affiche le nom du programme |
| 01 | `ft_print_params.c` | affiche les arguments, un par ligne |
| 02 | `ft_rev_params.c` | affiche les arguments dans l'ordre inverse |
| 03 | `ft_sort_params.c` | affiche les arguments triés en ordre ASCII |

## Compilation

Les exercices sont des fonctions seules, sans `main`. Pour les tester, on les compile avec un `main` de test :

```bash
cc -Wall -Wextra -Werror ex00/*.c main.c
```
