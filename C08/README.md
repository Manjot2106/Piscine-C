# C08

Fichiers d'en-tête, macros et structures.

## Exercices

| Ex. | Fichier | Rôle |
|---|---|---|
| 00 | `ft.h` | prototypes des fonctions de base |
| 01 | `ft_boolean.h` | type `t_bool` et macros `TRUE`, `FALSE`, `EVEN`, `SUCCESS`… imposés par le sujet |
| 02 | `ft_abs.h` | macro `ABS(Value)` |
| 03 | `ft_point.h` | structure `t_point` |
| 04 | `ft_strs_to_tab.c` | transforme `argv` en tableau de structures `t_stock_str` (taille, chaîne, copie) |
| 05 | `ft_show_tab.c` | affiche ce tableau de structures |

## Notes

Les macros avec paramètres de `ft_boolean.h` et `ft_abs.h` sont demandées par le sujet, même si la Norme les interdit ailleurs.
