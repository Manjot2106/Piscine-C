# C09

Bibliothèques statiques et Makefile.

## Exercices

| Ex. | Fichier | Rôle |
|---|---|---|
| 00 | `libft_creator.sh` | compile les fichiers `.c` et crée `libft.a` avec `ar` |

| 02 | `ft_split.c` | découpe une chaîne selon un ensemble de séparateurs |
